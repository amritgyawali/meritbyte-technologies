Flutter is an open-source UI toolkit from Google for building apps for iOS, Android, the web and desktop from a single codebase written in the Dart language. Instead of wrapping each platform's built-in buttons and lists, Flutter draws every pixel itself, so an app looks and behaves the same on an iPhone and a budget Android phone. Meritbyte Technologies, a Nepal-based app and software development company, builds Flutter apps for businesses in Nepal and, remotely, in the USA, Australia, Canada and the UK.

## When is Flutter the right choice?

Flutter is a strong fit when:

- **You need iOS and Android at the same time** and do not want to pay for two separate codebases and two teams.
- **The design is custom and brand-heavy.** Because Flutter draws its own widgets, a bespoke interface looks identical on both platforms.
- **Your users are on mid-range Android phones.** Flutter compiles to native machine code and performs well on modest hardware, which matters in markets like Nepal.
- **The app must work offline,** for field staff, inspections or deliveries, and sync when a connection returns.

Consider [React Native](/technologies/react-native) instead if you already have a React web team who will maintain the app. Consider fully native Swift and Kotlin if the app is built around platform-specific hardware features from day one. And ask whether you need an app at all: our comparison of [PWA vs native app](/blog/pwa-vs-native-app) explains when a progressive web app is enough.

## Payments in Flutter apps

Payment rules depend on what you sell. Digital goods and subscriptions used inside the app generally must go through Apple's and Google's in-app purchase systems. Physical goods and services, such as food orders, bookings and deliveries, can use a regular payment gateway: Stripe and similar abroad, and eSewa, Khalti or Fonepay for customers in Nepal. ## Frequently asked questions

### What is Flutter?

Flutter is an open-source toolkit from Google for building apps for iOS, Android, the web and desktop from one codebase written in Dart. It draws its own interface rather than using each platform's built-in components, so apps look and behave the same everywhere, and it compiles to native code for good performance.

### Is Flutter better than React Native?

Neither is better overall. Flutter suits custom, brand-heavy designs and teams starting fresh, because it draws every pixel itself. React Native suits companies with existing React web developers, since they can share skills and some code. Both produce real iOS and Android apps that pass store review.

### Can one Flutter app run on both iOS and Android?

Yes. That is the main reason to choose Flutter. Most of the code is shared, with small platform-specific pieces for things like permissions, payments and notifications. You still need separate store listings, and the app is tested on real iPhones and Android phones before every release.

### How long does it take to build a Flutter app?

A focused first version with a handful of core screens and a simple back end often takes two to four months, depending on design, integrations and how quickly decisions are made.
